# Enterprise Cloud Architect – Mission 10

## Project Overview

This project demonstrates the deployment of a WordPress web application and a MySQL database using Docker Compose on an Ubuntu Server virtual machine running in VirtualBox.

## Group Project

**Course:** CCM101 – Cloud Computing Laboratory
**Activity:** Mission 10 – The Enterprise Cloud Architect

## Architecture Components

* **Host Machine:** Windows 11
* **Hypervisor:** VirtualBox
* **Server Operating System:** Ubuntu Server
* **Firewall:** UFW
* **Container Platform:** Docker Engine and Docker Compose
* **Web Application:** WordPress
* **Database:** MySQL 8.0

## Accessing the Application

When the virtual machine and required containers are running, open a browser on the host machine and visit:

`http://127.0.0.1:8080`
